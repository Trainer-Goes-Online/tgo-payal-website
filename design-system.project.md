# tgo-payal · project skin

Source of truth: `Payal Kothari Branding 3.pdf`. The LAYOUT follows the website mock on
page 06 of that PDF; the brain (`~/.claude/system/design-system.base.md`) applies, this
file only sets the skin.

## Tokens (supplied hexes only; softer tones are alphas of these)
- Oxblood `#5A0E14`: headlines, primary pills, links, the one accent
- Ivory `#F8F4EE`: page ground, header, cards, footer
- Sand `#D9C9B8`: tinted bands, quote band, icon circles, image panels
- Olive `#6B7058`: the one coloured band (Watch & Learn)
- Cacao `#3E2F28`: body ink (alphas for soft text and hairlines)

## Voices
- Playfair Display: headlines, card titles, quote lead, wordmark (tracked caps)
- Inter: body, nav (sentence case), tracked uppercase eyebrows and buttons
- Allura: handwritten notes only (hero, portrait), max one per section

## Page-06 motifs
Solid ivory header with tracked serif wordmark and an oxblood pill CTA; full-bleed photo
hero faded into ivory on the copy side; 4-up focus strip with sand icon circles; image/text
split blocks; photo-top cards with "ARROW LINK" footers; sand quote band with leaf shadow
and a vertical rule; one olive band; slim ivory footer. No dark bands, arches or rings.

## Choices
- Press logos sit grayscale on ivory tiles until hover (quiet wall), never recoloured.
- Proof (media clippings, before/afters) shown at native ratio, never cropped.
