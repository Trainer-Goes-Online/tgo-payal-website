# tgo-payal · project skin

Source of truth: `Payal Kothari Branding 3.pdf` ("Inside Out" visual direction). The brain
(`~/.claude/system/design-system.base.md`) applies; this file only sets the skin.

## Tokens (supplied hexes only; softer tones are alphas of these)
- Oxblood `#5A0E14`: headlines, the one accent, primary buttons
- Ivory `#F8F4EE`: page ground (with film grain)
- Sand `#D9C9B8`: washes, discs, arch backs, icon circles
- Olive `#6B7058`: one dark band (Trusted By)
- Cacao `#3E2F28`: body ink, one dark band (Podcasts) and the footer

## Voices
- Playfair Display: headlines, quotes, ordinals, wordmark (serif never below ~18px)
- Inter: body (300) and tracked uppercase labels (500, .24-.28em)
- Allura: handwritten accents only, max one per section, brand-kit phrases only

## Motifs (from the PDF)
Arch-topped portraits with an offset sand arch behind; thin oxblood rings; sand discs
behind objects; eyebrow = short rule + tracked caps; script note rotated ~-6deg.

## Concept-level choices
- C8: Private Consultations is the featured (oxblood) service card.
- C12: press logos keep their own colours on ivory tiles (multiply blend), never recoloured.
- Proof (media clippings, before/afters) shown at native ratio, never cropped.
